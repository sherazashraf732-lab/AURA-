# 01 — AURA Product Blueprint

## Product identity
**Name:** AURA  
**Tagline:** Your AI Powerhouse  
**Positioning:** A unified AI research, intelligence, creation, development and productivity workspace.

## Vision
AURA combines specialist AI tools and agents behind one coherent interface. Users can research, verify evidence, work with files, analyze data, create documents, develop software and automate workflows without jumping between disconnected products.

## Target experience
- One account and unified workspace.
- A central assistant that can coordinate modules and agents.
- Separate projects, chats, files, outputs and task histories.
- User-controlled memory and multilingual conversation.
- Animated premium interface across the entire application.
- Public web beta for 50–100 initial testers, with open signup and controlled quotas.
- Windows desktop client after web beta is stable.

## Product principles
1. Useful functionality over feature count.
2. Open-source reuse before custom implementation.
3. Trustworthy answers with source provenance.
4. Clear distinction between verified facts, inference and uncertainty.
5. Privacy, security and user control by design.
6. Accessible, responsive and performant animation.
7. Provider-neutral AI architecture.
8. Portability and documented operations.

## User roles
- Visitor: landing page, public product information.
- Registered user: private workspace, chats, projects and enabled modules.
- Admin: platform operations, abuse controls, usage overview and feature management.
- Support/operator role may be added later with least-privilege permissions.

## Primary journeys
1. Sign up → verify email → create workspace → ask central assistant.
2. Start research → view plan/agents/sources → review evidence → export report.
3. Upload a document → ask questions → extract data → create output.
4. Analyze CSV/XLSX → clean data → chart → export.
5. Create a project → save chats/files/instructions → resume later.
6. Create workflow → test safely → approve → execute → inspect logs.
7. Configure provider key → test connection → select model → monitor usage.

## Explicit scope
Build the 20 core modules and only these five additional strategic features:
1. Universal Workspace + Project Continuity Engine.
2. Memory Intelligence.
3. Live AI Agent Control Room.
4. Model Arena.
5. Evaluation Center.

Do not silently add other optional feature families to the initial approved scope. Voice, video intelligence, local model hosting, browser agent and other expansion ideas remain future candidates only.

## Release strategy
- Release A: foundation and secure public web beta.
- Release B: core intelligence and creation.
- Release C: development and automation.
- Release D: advanced file intelligence.
- Release E: desktop client.
